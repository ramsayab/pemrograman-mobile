## Cara Menjalankan ChessWar Mobile

Pastikan Flutter SDK dan emulator atau perangkat Android sudah terpasang, lalu jalankan perintah berikut dari folder utama repository:

```bash
cd lib/UTS/chesswar_mobile
flutter pub get
flutter devices
flutter run
```

Perintah `flutter devices` digunakan untuk melihat perangkat yang tersedia. Jika terdapat beberapa perangkat, jalankan aplikasi pada perangkat tertentu dengan perintah berikut:

```bash
flutter run -d <device-id>
```
